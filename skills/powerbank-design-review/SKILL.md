# 充电宝资料分析与画板复用

把已有设计研究成可复查的连接关系和约束，再按当前需求选择参考。资料学习的交付物是知识库；只有用户要求设计时才推进新工程。目标软件优先沿用用户选择；本技能的画板准备示例面向嘉立创 EDA 专业版。

## 找到配套资料

先读工作区现有索引、入口和 AGENTS.md。若用户已允许自行找资料，从相关项目目录、桌面归档和已知附件目录定位；不要要求用户重新提供已能查到的路径。源图、原工作簿与压缩包保持只读，分析、解压副本与新工程用独立目录。

按路径登记文件，按 SHA256 判定内容重复。相同文件名不能证明同版；修改时间不能证明已发布。为原理图、PCB 各子板、BOM、需求、固件和变更记录建立配套表，不把“最新版”当作默认配套结论。

需要批量建立索引时运行 [scripts/inventory_sources.py](scripts/inventory_sources.py)：

```text
python scripts/inventory_sources.py <资料目录> --output <分析目录>/sources.json
```

它只生成文件索引、哈希和冲突分组，不读取电路；`indexed_only` 不能升级为“已学习”。压缩包目录与已解压、已阅读成员分别计数。

## 按证据深度研究

1. **身份与版本：** 分开保存原理图 Comment、LibReference、封装 PATTERN、PCB 当前位号文字、来源位号、BOM 采购型号和实物丝印。按完整订货后缀查手册；同系列不等于同引脚或寄存器。
2. **连接：** 先画电芯最高端、中点、负端及受保护输出端；再跟踪保护 MOS、分流电阻、主转换电感/开关节点和端口 MOS。每条路径给出器件、脚号、网络及来源位置。
3. **采样与控制：** 同时记录差分采样两端、滤波、参考地、NTC 阻值/B 值/返回点、通信电平和使能。网名相似不能合并；连线本身不能证明固件阈值或协议成功。
4. **跨文件核对：** 用当前 PCB 位号配对元件，再查焊盘网络；连接器镜像、极性器件、MOS 辅助焊盘和 NC/DNP 做专项核对。保留所有差异，不自动改线消除冲突。
5. **可复用约束：** 对确定事实写适用条件，对推断写依据，对冲突列出双方。先继续不依赖冲突的工作，只有实际选用该方案时才集中补问影响设计的缺项。

按当前资料类型读取对应说明，不必一次加载全部附件：

- BOM、需求、芯片资料或版本冲突：[evidence-and-versions.md](references/evidence-and-versions.md)。
- Altium SchDoc/PcbDoc 解析、旧位号、网表差异：[altium-connections.md](references/altium-connections.md)。
- 保护/采样电路复用和嘉立创工程验收：[power-paths-and-handoff.md](references/power-paths-and-handoff.md)。

PDF 中的电路、连接点和参数表需视觉复核相关页；文字提取只能辅助定位。工作簿读取值、公式和缓存值，引用工作表与单元格；分析任务不要为了读取而重存源文件。可用 PDF/表格技能时按其只读分析流程处理。

## 输出能继续工作的知识库

按任务规模提供一个入口和必要专题，避免把所有原始解析记录堆进总报告。保留以下内容：

- 每个型号/版本实际读到的范围、源路径和哈希；不同子板分别列出。
- 主电源、保护、采样及接口的关键引脚表；适用时附原图局部或定位图。
- 差异表：两侧证据、实际影响、目前结论、需要哪项资料或验证才能解决。
- 后续画板可采用的模块、条件与待核对项；机器证据放 JSON 或其他便于检索的格式。

事实至少能追到 `源文件哈希 + 页码/单元格/记录位置`。对于几何解析，另保留脚号、网络名、当前位号来源和不支持的图元。证据结构示例见 [evidence-and-versions.md](references/evidence-and-versions.md#最小证据记录)。

最后检查引用文件可访问、JSON 可读取、关键提取结果与原文件相符；必要时复核源哈希。报告分别说明文件解析、EDA 导入、ERC/DRC、制造输出和硬件验收的执行状态。解析器“零错误”、保存规则、焊盘网络分配均不等于整板通过检查。

将经验打包公开时，发布可移植方法与工具；源工程、采购表、真实物料编号、客户信息和绝对路径另按明确发布范围处理。该技能不自动授权上传或发布任何项目资料。
